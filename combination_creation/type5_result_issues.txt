Issues found in 民泊清掃 (type_5) scrape results
================================================
Checked:
  - zehitomo_main.xlsx rows 176–220 (45 contractor rows)
  - output.json → services.民泊清掃 (combination1–15)

Date reviewed: 2026-11-23


1) Heavy duplicates (same contractors again and again)
-----------------------------------------------------
Only about 8 unique companies across 45 rows.
Examples: CTKサポート and mimosa美装 each appear ~12 times.
Same pros are re-saved for every nearby postal / combination.

Need: stronger dedupe (e.g. by name + Zehitomo URL across the whole sheet),
      or only append new contractors.


2) Contact fields mostly empty
------------------------------
For rows 176–220:
  - 電話番号 empty ~87% (39/45)
  - アドレス (email) empty ~87%
  - オフィシャルサイト empty ~93%

From combination4 onward, almost every contractor in output.json also has
no phone / email / site.

Need: more reliable chat/contact extraction
      (or clearly mark “not available on profile”).


3) Zehitomo profile URL often missing  *** BOSS: please improve ***
-------------------------------------
23/45 rows have no ゼヒトモ URL.
Especially bad on azimon runs (combination1 / 4 / 7 / 10 / 13:
all 3 contractor URLs empty). Earlier scrape: azimon ~100% missing,
tasnia/mustakim ~20–27% missing.

Root causes found (2026-11-23):
  - New Google SERP uses opaque `/goto?url=CAES...` (not classic
    `/url?q=https://zehitomo.com/...`), so old scraper skipped all links.
  - Automated Chrome hits google.com/sorry (bot check) after rapid searches.
  - Short names (本田/久保) can match wrong pros if substring match is used.

Fixed (2026-11-23):
  - Human-like Google search + name/slug match in app/services/browser.py
  - Wired into app/services/tools.py find_url_to_access_to_contractor
  - Tester confirmed on tasnia (--failing-defaults --wait-captcha)
  - Avoid hot profiles (azimon /sorry); prefer cooler profile for Google.


4) Wrong Zehitomo URL for this service
--------------------------------------
エアクリーンヤマダ was saved with:
  .../pro/ventilator-cleaner
while scraping 民泊清掃.

Need: prefer service-matching profile URL,
      or strip/normalize wrong service suffix.


5) Phone number formatting broken in the sheet
----------------------------------------------
09088957605 becomes 9088957605.0 in Excel
(leading 0 dropped, stored as a number).
Mixed formats also appear (09088957605 vs 080-4534-4545).

Need: always write phone as text
      (keep leading 0, consistent 090-xxxx-xxxx style).


6) Inconsistent company names (「さん」)
---------------------------------------
output.json often has names like エイティーワンさん.
Sheet strip_san() removes 「さん」 (good), but raw output is inconsistent;
some rows already had no 「さん」.

Need: normalize names in scrape output before save.


7) Address quality inconsistent
-------------------------------
- Ideographic spaces (\u3000) vs normal spaces
- Odd hyphen form: 北海道札幌市-南区…
- Sometimes missing prefecture: 札幌市北区 / 札幌市豊平区…
- Same company can have different address text across rows
  (e.g. エイティーワン)

Need: normalize address text (spaces, 北海道 prefix, punctuation).


8) Combination column not clear in the xlsx
-------------------------------------------
Sheet writer stores combination_id, but in zehitomo_main.xlsx that column
header is blank / None, so it is hard to audit which combo produced which row.

Need: keep a clear 「combination」 column in the delivered sheet.


9) Low answer diversity in type_5 options (upstream)
----------------------------------------------------
Almost all 15 combinations use the same answers:
  戸建タイプ + 可能な限り早く + 1R/1K/1DK/1LDK + 駐車場あり（無料）
Only the postal code changes → results heavily overlap.

Need: confirm with whether type_5 sheet should vary Q1–Q4 more,
      not only location.


10) Official site almost never filled
-------------------------------------
Only Hoan Clean has a website; almost everyone else is blank
even when a Zehitomo URL exists.

Need: improve “other website” extraction from chat / profile.


Highest priority
----------------
1. Dedupe
2. Missing phone / email
3. Missing Zehitomo URL
4. Phone-as-number Excel bug
5. Wrong service URL (ventilator-cleaner on 民泊清掃)
